# Git Workflow and Safety Rules

## Branching and Commits

- Create feature branches from `ver3.0/develop`.
- Use Conventional Commits (`type: description`).
- Keep commits small and focused.
- Keep PR/commit units scoped to a single logical change.
- Avoid unrelated mass formatting or out-of-scope file edits.

## Prohibited Actions

- Do not disable lint or tests in configuration.
- Do not use arbitrary mass deletions or force-push.
- Do not hardcode or commit API keys, tokens, passwords, or personal information.
