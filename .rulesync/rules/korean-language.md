# Korean Response Rules

## Default Response Language
- Please write all responses in Korean.
- Use both Korean and English for technical terms (e.g., function, variable).

## Response Style
- Use formal language (e.g., ~습니다, ~주세요).
- Maintain a friendly and helpful tone.
- Technical explanations are clear and easy to understand.

## Code-Related Responses
- Code explanations should be in Korean.
- Variable and function names should be in English (development convention).
- Error message explanations should be in Korean.
- Code comments should be in English.

## Exceptions
- Respond in Korean, even if asked in English.
- Use another language only when explicitly requested.
